# 乐道技能包 · Ledao Skills

豆包创作体系开源技能包：**11 个 skill**，覆盖「定位 → 选题 → 对标 → 判断 → 洗稿 → 去AI味 → 诊断改稿」完整内容生产线。

核心技能是 **乐道｜爆款对标智能体（benchmark-advisor）**：判断一个小红书账号 / 一条内容到底值不值得对标，判断链严格固定为 **人群质量 ＞ 变现结构 ＞ 内容表现**，数据再高也不能翻盘。

## 一句话安装（豆包工作）

把本仓库地址发给豆包工作，然后说：

> "帮我装乐道技能包"

豆包会自动从本仓库拉取全部 11 个技能并安装。安装完成后重启豆包工作客户端即可使用。

> 备选：手动安装——把 `skills/` 下每个文件夹复制到你的豆包技能目录
> `workspace/.user_skills/`，重启客户端。

## 技能清单

| 技能 | 作用 | 一句话说明 |
|---|---|---|
| **benchmark-advisor** | 对标决策参谋 | 判断账号/内容值不值得对标，结论：值得 / 不值得 / 不可放大 / 待补证据 |
| keyword-generator | 定位→关键词 | 把业务定位翻译成搜索关键词（人群/能力状态结果/服务承接分组） |
| benchmark-finder | 找对标账号 | 自动挖掘候选对标池，B/C 端区分、跨行业优先、AI 类补足 |
| daily-picks | 每日爆款推荐 | 对标账号+全网关键词采集，Top3 + 每日推荐（含原标题/原赞数/为什么推荐/形式） |
| pattern-matching | 句式对版表 | 把对标原句拆成句式骨架，套你自己的真实素材 |
| ai-retell | AI 重讲洗稿 | 原爆款句式一字不改，前面加"AI"，产出 AI+赛道差异化版本 |
| de-ai | 去 AI 味 | 扫描排比/对仗/金句堆砌等 AI 写作特征并改写 |
| viral-rewrite | 爆款洗稿 | 原句式换人群词，套用户真实素材洗成自己的内容 |
| lead-topics | 获客选题生成 | 按客户阶段生成10个获客漏斗选题（吸引关注/精准客户/信任/成交铺垫） |
| inspiration-board | 选题灵感工作台 | 自动找对标 + 搜索代表性内容，输出灵感台 HTML |
| toc-high-ticket-content | ToC高客单内容诊断改稿 | 咨询师/疗愈师/家庭教育等知识型个体：五维诊断（流量/精准度/高客单承接/人味/平台风险）+ 对标迁移 + 完整改稿 + 发布复盘 |

## 使用方式（对话触发）

- **判断值不值得对标**（先给定位，再丢对象）：
  > "我的定位是XX。这个账号值不值得对标？<账号名 / 标题 / 链接 / 截图>"
- **只要搜索关键词**：
  > "我的定位是XX。帮我出小红书搜索关键词。"
