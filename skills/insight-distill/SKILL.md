# 行业认知蒸馏器

把用户所在行业的"高手认知"蒸馏成可用的观点弹药：10 条稀缺、有高度、一句话就能立住的中心思想。

## 用途

解决"脑子里没东西"：洗稿、选题、写内容时没有自己的判断和观点，只能套通用话术。本 skill 在写内容前，先把行业里真正高手的稀缺认知找出来、蒸馏成观点库，让内容有"真东西"。

## 输入（先收全，缺就问，最多 3 问）

1. **行业/方向**：如"家庭教育""婚姻情感咨询""疗愈师获客"
2. **目标人群**（可选）：如"小学初中高中家长""婚姻内耗中的中年女性"
3. **结合点**（可选）：如"AI+教育""高客单+婚姻咨询"

用户只给了行业就开工；缺的信息在输出中标注"待补充"。

## 流程

1. **拆领域**：把方向拆成目标客户真正关心的子问题（至少 5 个）。
   例：家庭教育+AI → 孩子怎么学 / 家长怎么教 / 家庭氛围怎么调 / 学校vs家庭 / AI时代什么能力值钱。
2. **调研**（并行多源，每源必须记出处）：
   - 学术：scholar_search 搜近 3 年该领域研究与综述
   - 网络：general_search 搜该领域知名作者、学者、头部从业者的最新文章与访谈
   - 爆款：video_search / image_search 搜该领域头部专家、大咖的爆款内容
   - 书籍：搜索该领域公认代表作与其核心论点
   每个来源记录出处（作者/书名/标题/链接）；拿不到出处的标"待核实"。
3. **蒸馏**：从语料里提取真正稀缺的认知。过滤标准见 `references/quality-standard.md`。
   目标不是"整理信息"，是"找出别人不知道、但一听就成立的观点"。
4. **金句化**：每个认知写成一句话——清楚、稀缺、有判断。写法见 `references/quality-standard.md`。
5. **输出 10 条**：每条包含四要素（见下）。

## 输出格式

```
【领域】家庭教育 × AI
【拆解】5 个子问题…
【10 条稀缺认知】
01 ｜ 核心观点（1-2 句白话）
   金句版：「一句话，可直接当标题/开头/观点句」
   出处：谁说的 / 哪里来的（可追溯，拿不准标待核实）
   稀缺点：和满大街观点的区别（一句话）
02 …
…
【使用建议】哪几条适合做选题、哪几条适合当洗稿观点、哪几条适合诊断时用
```

## 真实性红线

- 不编造专家观点：没有搜到的观点标"待核实"，不冒充大师说过
- 不伪造出处：出处写搜索到的真实来源，拿不准就写"网络检索待核实"
- 不输出满大街的"正确废话"：如"AI 是工具不是威胁"这种人人皆知的不算稀缺认知
- 判断"稀缺"以本 skill 的过滤标准为准，不因模型觉得"有道理"就放行

## 衔接

蒸馏出的 10 条可直接供：
- daily-picks / inspiration-board：当选题弹药
- viral-rewrite / ai-retell：当洗稿时的"观点素材"（替换/强化原爆款的观点位）
- toc-high-ticket-content：当诊断时的"作者判断"参考
- liujin-rewrite：当需要"有高度的判断"时的来源
