# 对标账号挖掘器

自动找出"同打法、同业务端、同客单价、同平台"的爆款账号。

## 输入

1. **定位**：赛道、客单价、服务谁
2. **业务端**：B端还是C端（决定对标方向，混端必错）
3. **关键词**：用 `keyword-generator` 生成15个（或用户直接给）
4. **平台**：小红书/抖音/视频号

## 流程

1. 用2-3个关键词在目标平台搜（B端搜"教XX获客/变现/做IP"，C端搜赛道爆款；AI+赛道补AI词）
2. 按"最多点赞"排序，看前20条爆款
3. 统计高频博主（谁发的多、赞数高）
4. **过滤**：
   - B端只看B端账号（教从业者/老板变现），C端账号直接跳过；反之亦然
   - **跨行业优先**（同打法 > 同行业，同行业容易互相抄）
   - AI类占对标池1/3以上（若用户差异化是AI+）
   - 该平台赞数低 = 主战场不在这，跳过
5. **输出3-5个候选**，每个一句话特点（粉丝量 + 定位 + 为什么对味），让用户挑1-2个

## 小红书实战

- 搜博主名或关键词：`https://www.xiaohongshu.com/search_result?keyword=XX&type=51`
- 抓笔记标题/链接/博主/日期/赞数（抓取脚本见 `inspiration-board` 第0.5步）
- 筛选：**最近30天 + 百赞以上**
- 从全网（抖音/官网/文章）找到的候选，若用户要求，需逐一核实其在目标平台的实际账号和流量

## 验收

- [ ] 候选账号业务端与用户一致
- [ ] 含跨行业对标
- [ ] AI类占比达标（若需要）
- [ ] 每个账号有定位说明

## 衔接

候选对标池存为用户的对标账号清单，供 `inspiration-board`（灵感台）和 `daily-picks`（每日爆款推荐）使用。
