# 爆款对标智能体（定位→搜索关键词）

把用户的定位翻译成"搜什么才能找到对味爆款"的15个搜索关键词。

## 输入（先问全，缺了就问）

1. **赛道**：做什么业务（疗愈/咨询/教培/AI+……）
2. **业务端**：B端（服务从业者/老板）还是 C端（直接做内容给消费者）——决定关键词方向，混端必错
3. **客单价**：产品卖多少钱（高客单/中低客单）
4. **目标人群**：主要服务谁（咨询师/疗愈师/老板/……）
5. **差异化**：是不是"AI+赛道"

## 生成规则

1. **按业务端定关键词骨架**：
   - **B端**：核心词 = 赛道 + 获客/变现/做IP/陪跑/招生（如"咨询师 获客""疗愈师 变现""教培 招生"）
   - **C端**：核心词 = 赛道 + 内容方向/受众痛点（如"疗愈 冥想""心理咨询 自救"）
2. **跨行业扩展**：不要只搜自己行业，加2-4个"同打法"行业（B端：教培招生/律师获客/保险团队/美业/房产/老板IP；C端：情感/成长/自律/副业）
3. **AI类补足**：用户差异化是"AI+赛道"时，AI类关键词（AI+商业/AI+IP/AI+获客/AI+一人公司/AI工具）至少占关键词池1/3
4. **平台生态补足**：加平台生态词（小红书：素人/笔记/涨粉/变现；抖音：口播/起号/直播；视频号：私域/直播）

## 输出格式

15个搜索关键词，按5类标注：

| 类 | 关键词 | 用途 |
|---|---|---|
| 赛道核心 | … | 找同赛道爆款 |
| 变现逻辑 | … | 找高客单打法 |
| 跨行业 | … | 找同打法对标 |
| AI类 | … | 补AI对标 |
| 平台生态 | … | 平台内搜索 |

## 参考示例（B端 AI+咨询师 高客单）

商业IP、副业、赚钱、知识付费、女性成长、一人公司、高客单经营、大健康、教培、独立老师、家庭教育、个人IP、商业、AI、疗愈

## 验收

- [ ] 15个关键词，5类齐全
- [ ] B/C端匹配（不混端）
- [ ] AI类占1/3（若差异化是AI+）
- [ ] 含跨行业词

## 衔接

生成的关键词直接喂给 `benchmark-finder`（搜对标账号）和 `daily-picks`（每日爆款推荐）。
