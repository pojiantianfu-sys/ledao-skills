# 钩子分类与去 AI 味清单

## 短视频钩子类型（对标账号视频分类用）

每条视频在灵感台里要标一个钩子类型，方便用户快速扫：

| 钩子类型 | 特征 | 例子 |
|---|---|---|
| 反常识金句 | 第一句就否定大众默认 | "AI 写文案是 AI 最垃圾的功能" |
| 晒数字 | 第一句砸一个极端数字 | "2 小时 1 万条"、"一个月 1300 万" |
| 自曝反差 | 承认自己不擅长的事 | "我做抖音 5 年连飞书都不会" |
| 蹭权威 | 拿大佬/大厂做对比 | "我比黄仁勋早三个月" |
| 学员证言 | 学员自己说话/结果 | "上了 2 天课，回日本降本 100 万" |
| 命令断言 | 直接命令观众 | "别培训了，直接筛" |
| 对比挑衅 | "同一个 X，凭什么他 Y" | "同一个 AI，凭他得到的比你多" |
| 场景演示 | 现场录屏/操作 | "带你看我的工作台" |
| 甩锅给你 | "不是 X 不行，是你 Y" | "不是 AI 不行，是你没带好它" |
| 道德立场 | 站边、下判断 | "不尊重弱者做不成大 IP" |

## 去 AI 味清单（写逐字稿时对照）

写完逐字稿后逐条检查，中了任何一条就改：

### 句式上要删的

- [ ] 超过 3 个短句的排比（"我们要 A、要 B、要 C"）
- [ ] 对仗工整的两句话（"不是……而是……"用了超过 1 次）
- [ ] 每句都像金句——真人说话会有废话
- [ ] "赋能 / 抓手 / 闭环 / 颗粒度 / 底层逻辑 / 顶层设计"
- [ ] "在这个 XX 的时代" 开头
- [ ] "今天我想跟大家分享"
- [ ] "首先、其次、最后"这种结构词

### 内容上要加的

- [ ] 至少一个具体的人（"上周有个做家庭治疗的老师"）
- [ ] 至少一个具体的数字（不是"很多"，是"8 个员工砍到 1 个"）
- [ ] 至少一句口语词（"真的"、"我跟你说"、"你猜怎么着"、"姐妹"、"说白了"）
- [ ] 有停顿、有转折（"然后呢？"、"结果你猜怎么着"）
- [ ] 第一人称叙事，不要第三人称讲道理

### 长度上

- [ ] 60 秒口播 180-220 字，不要写满 300 字
- [ ] 开头 3 秒必须把判断甩出来，不要铺垫
- [ ] 结尾不要"关注我了解更多"这种 CTA，留一句余味或者一个反问

## 真人语气 vs AI 腔 对照

| AI 腔（删） | 真人（改） |
|---|---|
| "AI 时代知识 IP 面临的核心挑战是……" | "你学了那么多 AI 课，生意变好了吗？" |
| "通过 AI 工具实现效率提升与商业升级" | "我让 1 个人顶 7 个人" |
| "我们致力于为咨询师提供一站式解决方案" | "我陪跑了 1000 多个咨询师" |
| "赋能个体知识从业者实现商业闭环" | "别做工作室了，做一人公司" |
| "这是一个值得深思的问题" | "你客户凭什么找你，不找一个 AI？" |
