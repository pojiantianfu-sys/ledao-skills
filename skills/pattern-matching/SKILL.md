# 句式对版表

核心方法：不要模仿对标账号的风格，直接复刻句子结构，把内容换成用户自己的。

## 10种句式骨架

| # | 类型 | 结构 | 例子 |
|---|---|---|---|
| 1 | 极端断言 | X是X最Y的功能，没有之一 | AI写文案是AI最垃圾的功能 |
| 2 | 领先叙事 | 我比X早X个月，全体员工用上Y | 我比黄仁勋早三个月用上Codex |
| 3 | 命令记住 | 所有X记住一句话：Y | 所有老板记住一句话：给聪明人配算力 |
| 4 | 晒配置型 | 我们X人，人人X | 70人公司，人人Pro |
| 5 | 重新定义 | 不是X不行，是你没Y它 | 不是AI不行，是你没带好它 |
| 6 | 公式金句 | 一个X + X = 10个Y | 一个聪明人+算力=10个普通人 |
| 7 | 自曝反差 | 我做X年，连X都不会用 | 我做抖音5年，连飞书都不会用 |
| 8 | 数字暴击 | X小时产出X条 / 一个月X万 | 2小时产出1万条短视频 |
| 9 | 命令断言 | 别X了，直接Y | 别培训了，直接筛 |
| 10 | 蹭权威 | X公司在做Y，我一年前就开始了 | Meta在蒸馏员工，我一年前就开始了 |

## 流程

1. 从对标账号爆款里挑出钩子最冲、最有辨识度的 **8-12条原句**
2. 两列表格：**左列原句，右列用户版本**
3. **右列只用用户真实素材**（粉丝数/营收/学员数/产品/经历），不编学员案例，不把对标账号的案例当用户的
4. **AI+赛道用"AI重讲"**：原句式前面加"AI"，或把人群换成用户受众

## 验收

- [ ] 原句一个字没改
- [ ] 右列全是用户真实素材
- [ ] 句式骨架不动，内容全换
- [ ] 给的是"能直接发"的标题，不是公众号腔

## 衔接

对版表挑中的句子，交给 `viral-rewrite`（写完整稿）或 `ai-retell`（AI重讲版）。
