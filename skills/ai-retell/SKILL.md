# AI重讲洗稿法

当用户差异化是"AI+某个赛道"（AI+知识IP、AI+高客单、AI+咨询师），把对标原选题"AI化"。

## 核心操作（三选一或组合）

1. **原句式前面加"AI"**：
   - 原句："如何吸引高端客户看一眼就买"
   - AI版："如何用AI吸引高端客户看一眼就买"
2. **把人群换成用户受众**：
   - 原句："我把AI工具免费公开，为什么更赚钱"
   - 用户版："我把AI测评免费公开，为什么更赚钱"
3. **把工具词换成用户真实动作**：
   - 原句："AI写文案是AI最垃圾的功能"
   - 用户版："用AI写公众号，是知识IP对AI最大的浪费"

## 规则（同 viral-rewrite）

- **原句式一个字不改**（只换人群词/工具词）
- **只用用户真实素材**（AI测评、AI工作台、AI工具——用户真做过的动作，不编）
- **去AI味**：AI化≠堆AI词，不写"赋能/抓手/闭环/降维打击"
- **直接给最终版**（标题 + 口播/图文 + 形式）

## 验收

- [ ] 原句式没动
- [ ] AI元素是用户真实动作（测评/工作台/工具），不是编的
- [ ] 没有AI腔，能直接念
