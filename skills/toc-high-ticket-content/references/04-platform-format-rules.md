# 04_平台内容形式执行库 V1.0

# 一、用途

本规则用于判断和修改不同公域平台、不同内容形式的表达。

核心原则：
同一个观点，可以跨平台；
同一篇稿件，不能默认原样跨平台。

平台变化时，需要重新判断：
- 用户进入内容的方式
- 注意力长度
- 标题承担的任务
- 开头速度
- 信息密度
- 语言形式
- 风险位置

# 二、跨平台共同原则

无论采用什么形式，都先保证：
- 目标客户能认出自己
- 开头尽快进入问题
- 一篇只处理一个主要问题
- 内容持续推进而不是重复
- 保留作者真实判断
- 案例真实
- 有适度承接
- 检查平台风险

平台适配不能改变事实。

不能为了短视频冲突感夸大结果。

不能为了小红书点击制造未经判断的心理标签。

不能为了视频号安全把内容修改成没有观点的空话。

# 三、小红书图文

## 1. 标题与封面承担主要点击任务

用户首先看到的通常不是完整正文。

因此优先判断：
"封面/标题有没有让目标用户产生'这和我有关'的感觉？"

标题优先包含：
- 精准人群
- 具体场景
- 现实冲突
- 结果
- 反常识判断

避免纯知识标题：
"关于亲子沟通的几个建议"

可以更加具体：
"孩子越大越不愿意跟你说话，先别急着学沟通话术"

前者在讲知识。
后者先进入目标用户的问题。

## 2. 前100—150字

正文不要花很长篇幅解释背景。

尽快进入：
用户处境 → 冲突 → 作者判断。

如果前面删掉200字正文才真正开始，通常说明开头过慢。

## 3. 图文不是论文

避免：
- 大量专业术语
- 连续定义概念
- 每一部分都像课程章节
- 为了完整把一个问题讲成知识大全

小红书用户首先需要：
认出自己的问题。

再进入作者的专业判断。

## 4. 也不能过度碎片化

图文不是把一句话拆成一行就会更好读。

如果是深度内容，可以使用自然段完整展开。

判断标准不是：
"句子够不够短。"

而是：
页面有没有明显的信息层级，每一部分有没有继续阅读的价值。

## 5. 收藏价值

收藏价值不等于：
"5个方法"
"10句话术"
"一个万能模板"

高客单内容的收藏价值也可以来自：
- 一个判断框架
- 自我检查问题
- 不同情况的区分
- 处理顺序
- 一个值得反复思考的专业判断

避免长期依靠资料、清单和模板吸引用户。

否则可能产生大量低价技巧需求者。

# 四、小红书短视频

## 1. 前3—5秒

视频首先解决：
"为什么我要继续听？"

可以采用：
- 具体冲突
- 精准状态
- 明确判断
- 用户正在经历的场景
- 反常识结论

避免：
"大家好，我是……"
"今天跟大家分享三个……"
"最近很多朋友问我……"

除非作者本人已经拥有较强的熟人流量。

## 2. 口播必须能说出口

检查每一句：
"真人会这么讲话吗？"

删除：
- 过长复句
- 连续抽象概念
- 书面连接词
- 一口气包含四五层逻辑的句子

一句话尽量承载一个主要信息。

## 3. 短视频不是图文分行

错误方法：
把1500字图文每句话换一行，直接作为口播。

正确方式：
重新决定：
"这个视频到底只想让用户记住什么？"

通常1—3分钟只解决一个核心问题。

原图文里其他内容可以成为下一条视频，而不是全部塞进去。

## 4. 保留过程，但删除重复

口播可以有：
"比如……"
"你会发现……"
"我见过很多这样的情况……"

等自然语言。

但不要同一个观点：
结论一次；
解释一次；
举例一次；
再总结一次；
最后升华一次。

视频节奏尤其需要向前走。

## 5. 字幕也要检查风险

风险检查不能只看口播稿。

同时检查：
封面＋标题＋口播＋字幕。

有时正文表达较谨慎，但封面为了点击重新使用：
疾病标签、绝对结果、人格诊断、效果承诺。

风险仍然存在。

# 五、视频号

视频号内容同样需要：
具体问题、明确判断和用户代入。

但涉及以下内容时采取更加谨慎的公开表达：
- 心理
- 医疗
- 疗愈
- 未成年人
- 健康
- 咨询服务
- 案例
- 转化

不能因为某个词在其他平台出现过，就推断视频号一定适合。

## 视频号口播

尽量做到：
- 开头直接
- 观点清晰
- 语言自然
- 案例不过度暴露
- 专业判断能够听懂
- 结尾不过度营销

不要为了"专业"把口播写成演讲稿。

# 六、公众号

如果用户明确需要公众号内容，可以允许更完整的：
- 真实经历
- 思考过程
- 案例
- 认知变化
- 观点展开

公众号不要求像短视频一样每句话都制造刺激。

但仍然需要：
具体标题＋有效开头＋持续的信息推进。

## 公众号允许过程感

作者可以讲：
以前怎么想；
发生了什么；
为什么开始怀疑；
后来看到什么；
判断怎样发生变化。

这些过程本身可以建立信任。

但：
过程感 ≠ 重复解释。

如果删除一段以后，读者没有损失新的事实、经历、画面、情绪或判断，这段通常可以删除。

# 七、长内容转短视频

不要"压缩全文"。

先回答：
"原文最值得做成视频的那个冲突是什么？"

然后只提取：
一个问题＋一个判断＋必要证明＋一个自然结尾。

一篇长内容可以拆成多条短视频。

不要为了"忠于原文"把所有观点塞进一条视频。

# 八、短视频转图文

不能简单把字幕拼起来。

需要补充：
- 必要上下文
- 更完整的案例
- 判断依据
- 阅读层级
- 用户可以停下来思考的内容

短视频依靠声音、表情和节奏建立的部分，在图文中需要重新组织。

# 九、标题与第一句话不必完全相同

标题负责：
让目标用户点进来。

第一句话负责：
让用户继续看。

二者可以不同。

但必须围绕同一个核心问题。

不能标题讲：
"二婚最重要的一个判断"

正文却主要讨论：
"女性如何爱自己"。

这属于内容错位。

# 十、平台适配顺序

用户要求把一篇内容迁移到另一个平台时，按以下顺序处理：

第一：保留母观点。
不要因为换平台创造另一个主题。

第二：重新设计入口。
标题和开头根据平台调整。

第三：调整信息密度。
决定保留多少内容。

第四：调整语言。
书面语、口语、自然段、短句分别处理。

第五：重新检查风险。
特别检查封面、字幕和结尾。

第六：重新设计行动入口。
不能机械复制原平台的转化方式。

# 十一、不要把所有平台写成一种风格

常见错误：
- 小红书图文像公众号
- 短视频像图文朗读
- 公众号像连续金句
- 视频号像营销课
- 所有平台结尾都是"需要帮助可以找我"

平台不同，表达任务也不同。

# 十二、平台规则的不确定性

平台规则、审核机制和投放要求可能变化。

没有最新可靠依据时，不得声称：
"这个词平台禁止。"
"这样一定限流。"
"这样一定能投。"

应采用：
"存在较明显风险，建议降低。"

或者：
"从公开表达安全角度建议调整，最终审核仍由平台决定。"

# 十三、公开版边界

本规则只负责内容形式适配。

不能因为"平台需要流量"而：
- 编造事实
- 夸大案例
- 制造疾病恐惧
- 增加效果承诺
- 使用不真实身份
- 牺牲客户隐私

平台适配改变表达，不改变事实。
