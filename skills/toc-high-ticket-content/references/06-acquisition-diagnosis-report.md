# 获客诊断与行动报告（06）

## 用途

处理"没客资 / 没咨询 / 没人加微信 / 来的人不精准 / 不知道内容怎么获客"一类的获客问题。

典型输入：
- 使用者的一句话问题（如"目前问题是没有客资"）
- 使用者最近发布的内容标题
- 可选：定位、客单价、数据、对标账号

输出：一份使用者可直接阅读、可交付的《精准获客复盘与行动报告》。

**适用范围**：任何 ToC 知识型服务者（咨询师、疗愈师、家庭教育、婚姻情感、女性成长等）。
**措辞约定**：统一用"你 / 使用者"，不预设使用者的身份与来源——对内部使用者和外部客户同样适用。

## 核心判断（写报告前先想清楚）

1. **先识别已有的场景入口，不要默认"没流量"。**
   使用者说"没客资"时，先看她有没有可获客的具体场景。
   例如："手机成瘾、学不进去、不上学、约她复盘"——这些本身就是精准痛点场景，
   说明她不是没有获客入口，而是没有把这些场景做成精准内容。
   一句话定调：高客单产品要的不是流量，是精准客户；问题往往不是"没流量"，而是"流量不精准"。

2. **精准漏斗五层（逐层对比，找到漏点）：**
   ① 公域笔记：选题/标题是否只戳精准人群痛点（不相关的人自动划走）
   ② 主页简介：有没有引流钩子/明确的下一步动作（领手册、自测表、方法论）
   ③ 进群：进群动机是否明确（为什么进群：领手册/做自测）
   ④ 群里转化：有没有引导加微信的动作（发完干货"顺便提一句"）
   ⑤ 微信成交：免费诊断 → 高客单转化

   每层判断三件事：对标怎么做 / 使用者现在怎么做 / 漏在哪。
   **从第几层开始漏，就只补那一层及以后，不跨层给建议。**
   常见结构：因为内容太杂 → 吸引来的人不精准 → 进群的也不是精准人群 → 群里自然没人加微信。
   不是产品不行，也不是专业不行，是前面的筛选没做好。

3. **对标拆解（有对标才做；没有对标则基于使用者现有内容拆"已有的获客要素"）：**
   拆 1—2 个对标账号的获客漏斗 + 各自 3 个关键设计，常见要素：
   - 标题只戳精准人群（不相关的人自动划走，精准人群停下来）
   - 简介直接放引流钩子（手册/方法论体系）
   - 内容 100% 聚焦一个方向 / 有自测型内容（"你家在哪个阶段"）/ 敢说反主流判断（建立"真懂"的信任）
   对标分析必须基于真实可核验内容，不编造对标账号没有的做法；只借鉴传播机制，不移植其独有案例与经历。

## 报告结构（默认输出顺序）

**一、一句话定调：你要的不是流量，是精准客户**
用使用者的真实客单价说明"越准越好"（定价以使用者实报为准，不写死、不代编）。
可举例说明"100 个泛粉不如 10 个真正有对应问题的人"。

**二、现状诊断：你的问题不是没流量，是流量不精准**
基于已有事实（粉丝数、进群数、加微信情况、内容方向数量）给出判断。
数据不足时标注"待确认"，不编数字。

**三、对标拆解：XX 是怎么精准获客的**
每个对标账号：获客漏斗（公域 → 简介 → 私信/评论 → 进群 → 加微信 → 成交）+ 3 个关键设计。
若使用者没提供对标，改为"你现有内容里的精准获客要素拆解"。

**四、你的获客漏斗哪里漏了**
五层漏斗对比表：对标怎么做 / 你现在怎么做 / 漏在哪（🔴）。
结论：从第几层开始漏、为什么后面的环节接不上。

**五、下一步：怎么把漏斗补起来**
分步骤动作，每步给目的：
① 做减法：只留 2 个方向（引流款约 60% + 信任款约 40%），停更分散方向——让刷到的人 3 秒内知道"你是解决哪个问题的"
② 改简介：加引流钩子（一句话定位 + 领什么手册/资料），给读者一个"下一步动作"
③ 做引流手册：10 页以内 PDF（自测 / 常见错 / 第一句话怎么说 / 一个公约 / 转折点 / 加微信入口）
④ 群里引导加微信：发干货时"顺便提一句"（领表 / 免费诊断 / 案例钩子），不硬推
⑤ 方法论命名：给使用者自己的方法起名字（如"XX 三阶段"），内容里反复提，建立"有体系"的专业感
动作以"能执行"为准，不给超出使用者现状的宏大方案。

**六、句式对版表（直接套）**
左列：对标账号原句（一字不改，标注来源账号）；右列：使用者版本。
按句式类型分组，例如：
- 反常识比喻（"孩子厌学，要像当渣女一样当妈妈" → 使用者对应版）
- 否定判断（"不要再把青春期的儿子当儿子看" → 对应版）
- 数字+前兆（"儿子一旦被养废了，会有这 5 个前兆" → 对应版）
- 身份特征 / 年龄警告 / 情绪共鸣
- 阶段拆解（"从第一天请假到彻底不上学，只差这一步" → 对应版）
- 反主流判断（"心理咨询为什么救不了厌学？" → 对应版）
- 硬标准 / 问题本质 / 失败复盘
右列只用使用者真实素材，不编。
详细对版方法见 `02-benchmark-rewrite-rules.md`。

**七、行动清单（本周）**
表格：动作 / 目的 / 时间。5—7 条，可执行，包含复盘项（本周几条私信、几条加微信、哪篇带来的）。

## 真实性红线（同核心 Instructions）

- 不编：案例、咨询过程、效果、成交数据、资历、平台规则。
- 不写死使用者的定价、资历、数据；以使用者实报为准，缺则标注待补充。
- 对标结论基于真实可核验内容；只借鉴传播机制，不移植其独有案例。

## 输入不足时的处理

- 缺定位/客单价/内容标题：先问最影响结果的 1—3 个问题（单次最多 5 个）。
- 已有信息能完成 80% 以上：先完成报告，标注"待使用者确认"的部分，不机械采访。
