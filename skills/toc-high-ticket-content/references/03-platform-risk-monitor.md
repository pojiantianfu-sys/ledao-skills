# 03_ToC平台风险监测库 V1.0

# 一、用途

本规则用于检查 ToC 公域内容中的明显表达风险。

适用于：
婚姻情感、家庭教育、心理咨询、疗愈、女性成长、身心健康及其他知识服务类内容。

风险检查范围包括：
标题、封面、正文、口播、字幕、标签、简介、案例和结尾转化。

核心原则：
风险监测不是敏感词替换。

同一个词放在不同账号身份、上下文和服务场景中，风险可能不同。

因此必须结合：
账号身份、内容语境、服务性质、目标人群、案例呈现和转化动作综合判断。

不得承诺：
"一定合规"
"一定能发"
"一定可投流"
"一定不限流"

统一采用：
"已降低明显风险，但最终审核仍由平台决定。"

# 二、风险输出方式

发现明显风险时，不要只说：
"这个词敏感，建议删除。"

尽量按照：
原句 → 风险类型 → 风险原因 → 推荐修改 → 对传播力的影响

进行判断。

例如：
原句：
"你老公就是典型的NPD。"

风险类型：
心理/人格诊断。

风险原因：
仅根据关系描述直接给第三方下人格障碍结论，容易形成未经专业评估的诊断式表达。

可以改为：
"如果一段关系里长期存在贬低、控制、否定和责任推卸，比给对方贴一个标签更重要的是先看这些行为正在怎样影响你。"

修改原则：
删除诊断，不删除冲突。

# 三、医疗与心理诊断风险

重点检查：
- 抑郁症
- 焦虑症
- 人格障碍
- NPD
- 创伤诊断
- 精神疾病
- 其他需要专业评估的医学或心理诊断

不能仅凭：
一段关系描述、几个行为、一次聊天、网络测试或作者主观判断，直接确认某人患有某种疾病或人格障碍。

尤其避免：
"出现这三个表现，就是……"
"这种男人都是NPD。"
"孩子已经抑郁了。"
"这就是典型人格障碍。"

更安全的处理方式是：
描述可观察行为和现实影响，而不是擅自确认诊断。

# 四、普通情绪疾病化

不要把：
难过、焦虑、敏感、疲惫、关系痛苦、暂时不想上学、压力大等普通或复杂状态，自动等同于疾病。

可以描述：
"持续低落。"
"长期处于高压力状态。"
"最近明显缺乏精力。"

而不是在没有依据的情况下直接给疾病结论。

如果内容涉及严重、持续或安全相关症状，应提示用户考虑寻求合适的专业评估，而不是仅依赖网络内容。

# 五、效果承诺

重点检查：
- 治愈
- 根治
- 保证恢复
- 保证挽回
- 保证复学
- 保证改变孩子
- 一次解决
- 几天见效
- 永不复发
- 百分之百有效

尤其注意标题中的隐性保证。

例如：
"三步让孩子重新爱上学习。"

即使没有"保证"两个字，也可能形成过强结果暗示。

更稳妥的表达可以落在：
帮助梳理、改善沟通方式、建立新的互动方式、探索问题、支持调整、提高理解和行动能力。

不要把服务描述成必然产生某个结果。

# 六、婚姻情感风险

## 1. 未经评估给伴侣贴人格标签

例如：
"NPD老公。"
"回避型男人一定……"

应优先讨论行为、关系模式和实际影响。

## 2. 操控和拿捏

避免把服务价值建立在：
"拿捏男人。"
"让他离不开你。"
"让男人主动回来。"
"一句话让他后悔。"

高价值婚姻内容更适合讨论：
关系判断、沟通、责任、边界、信任、修复条件和现实选择。

## 3. 结果承诺

不得承诺：
挽回、复合、阻止离婚、让伴侣改变。

## 4. 单一归因

不要把婚姻问题全部归因于：
女性不够温柔、不够有魅力、不够有能量；
或者简单把所有责任全部归给另一方。

复杂关系问题需要保留现实条件和双方责任。

# 七、二婚与复杂家庭

二婚内容不能只写：
"选对男人。"

需要意识到可能存在：
- 前任
- 孩子
- 财务
- 信任
- 家庭边界
- 居住安排
- 责任分配等现实变量

公开内容可以讨论判断框架，但不要根据少量信息替用户作出重大人生决定。

# 八、家庭教育与未成年人

这是需要重点谨慎处理的领域。

## 避免给孩子固定标签

例如：
"懒。"
"废了。"
"人格有问题。"
"天生叛逆。"

以及没有充分依据的疾病或心理诊断。

优先描述：
具体行为＋发生场景＋持续情况＋家庭互动。

例如不要直接写：
"孩子就是厌学。"

可以具体描述：
"一谈到上学就明显回避，最近早晨经常不愿出门。"

具体行为比标签更有判断价值。

## 不承诺结果

避免：
"让孩子复学。"
"让孩子成绩恢复。"
"彻底解决厌学。"
"一个方法改变孩子。"

可以讨论：
沟通方式、家庭支持、责任边界、可观察变化和进一步评估。

## 不把责任全部推给母亲

家庭教育内容不能为了制造冲突，把所有问题归结为：
"都是妈妈造成的。"

应区分：
家庭互动、学校环境、孩子自身状态、现实压力以及其他可能因素。

# 九、未成年人隐私

公开案例尤其谨慎。

检查是否组合出现：
- 年龄
- 学校
- 城市
- 班级
- 家庭职业
- 特殊事件
- 父母身份
- 可识别照片或对话

单个信息可能不构成识别，但多个信息组合可能暴露身份。

未成年人案例应更加严格匿名化。

# 十、心理咨询与疗愈

重点避免：
- 把成长支持包装成医疗治疗
- 承诺治愈创伤或疾病
- 普通情绪疾病化
- 详细公开咨询过程
- 未经授权展示可识别来访者
- 用严重心理问题制造恐惧后直接销售服务

如果作者提供的不是医疗服务，表达中应注意服务边界。

面对严重症状或安全风险，不应暗示普通内容或成长服务可以替代必要的专业评估和医疗支持。

# 十一、身体疗愈与健康

重点避免：
"比医院更早发现问题。"
"通过某种方式检测身体系统。"
"可以预测疾病。"
"某个情绪一定导致某种疾病。"
"做完就能改善某种疾病。"

不要把：
限制性信念、家庭关系、情绪压力与具体身体疾病建立未经证实的确定因果。

可以讨论：
压力体验、生活方式、主观精力感受、身心觉察和成长实践。

但不得暗示其可以替代医疗诊断和治疗。

# 十二、40+女性与女性成长

避免通过：
- 衰老
- 更年期
- 疾病
- 婚姻失败
- 被抛弃
- "女人过了某个年龄就……"

制造过度恐惧。

内容需要落到具体人生问题：
事业、关系、家庭责任、重大选择、生活结构、自我发展等。

不要只用：
"提升能量。"
"稳定内核。"
"找回自己。"

等抽象词替代真正的问题分析。

# 十三、案例与咨询隐私

真实案例公开前至少检查：
- 是否获得适当授权
- 是否能够识别当事人
- 是否展示了不必要的敏感细节
- 是否过度展示咨询过程
- 是否把个案结果包装成普遍效果

可以进行：
匿名化、身份模糊、删除无关细节、调整叙事顺序。

不得为了增强戏剧性补充不存在的细节。

# 十四、资质与专业身份

不得自行夸大：
- 专业资质
- 从业年限
- 服务人数
- 客户身份
- 媒体背书
- 学术成果
- 服务效果

如果用户没有提供，不能自动生成。

涉及专业身份时，以用户能够核实的信息为准。

# 十五、数据和案例效果

避免：
"90%的客户都……"
"所有学员都……"
"咨询一次就……"

如果用户没有提供真实可验证的数据，不得为了增强说服力生成数字。

即使用户提供了个案结果，也应避免暗示：
别人接受同样服务一定得到同样结果。

# 十六、引流与转化

检查：
- 明显站外联系方式
- 谐音、符号等规避监管式导流
- 评论关键词后私发联系方式
- 免费诊断、免费测评成为唯一钩子
- 心理、医疗、未成年人内容直接导向不适当服务

优先采用平台允许的：
站内互动、官方转化工具以及与正文直接相关的讨论入口。

平台规则可能变化。

不能因为某种方式过去有人使用，就判断现在一定安全。

# 十七、绝对化和恐吓表达

重点检查：
"一定。"
"必须。"
"所有。"
"唯一。"
"再不改变就晚了。"
"这样下去孩子就毁了。"

并不是出现这些词就一定存在问题。

关键看：
有没有事实依据，以及是否通过制造不必要恐惧推动转化。

风险修改不能简单把所有坚定表达改成：
"可能、也许、或许"。

这样会导致内容失去判断力。

正确做法是：
保留能够成立的判断，删除没有依据的绝对化。

# 十八、风险修改不能毁掉传播力

错误做法：
原句：
"每次跟孩子谈学习，最后都变成一场战争。"

直接修改为：
"部分家庭可能存在一定沟通问题。"

虽然更加模糊，却几乎失去传播价值。

更好的思路：
保留真实场景和冲突，修改真正有风险的诊断、承诺或绝对化内容。

风险优化的目标是：
降低不必要风险，而不是消灭观点、场景和冲突。

# 十九、风险等级

为了方便用户理解，可以采用：

## 低风险提醒

主要是表达优化、绝对化、隐私细节等值得检查的问题。

## 中等风险

存在较明显的诊断式表达、结果暗示、敏感案例展示或不恰当转化。

## 较高风险

涉及严重医疗/心理诊断、治疗承诺、未成年人敏感隐私、明显虚假效果、严重安全问题等。

风险等级只能用于帮助用户确定修改优先级。

不得将其表述为平台官方处罚概率。

# 二十、风险审稿输出模板

用户要求检查风险时，优先输出：

## 整体判断

是否存在值得优先修改的明显风险。

## 关键风险

最多优先指出3—5个真正重要的问题。

每个问题采用：
原句
风险类型
为什么
建议修改

## 修改后提醒

"已降低明显风险，但最终审核仍由平台决定。"

不要一次输出几十个"敏感词"，造成用户无法使用。

# 二十一、公开版边界

本风险库提供的是：
公开内容表达风险识别与修改建议。

不是：
医疗诊断、法律意见或平台官方审核结果。

平台政策可能变化。

在缺乏最新官方依据时，不得声称某句话：
"官方明确违规"
或：
"这样改一定可以发布"。
