# 每日爆款推荐

每天输出固定结构：两部分选题 + 1条每日推荐。

## 采集

- **平台**：小红书、抖音、视频号
- **对标账号**：用户的对标池（来自 `benchmark-finder`，或用户指定）
- **关键词**：`keyword-generator` 输出的15个，**按5类组织输出**：赛道核心 / 变现逻辑 / 跨行业 / AI类 / 平台生态（类目固定，词按用户定位生成）
- **筛选**：最近30天 + 百赞以上；窗口边缘条目（29-30天交界）标注"边缘，作参考"

## 输出结构

**执行口径**（输出开头写明）：采集窗口（如"2026-08-30~09-29 近30天"）、百赞门槛口径、数据核验状态（赞数无法实时回读时逐条标"待核验"）。

1. **【对标账号爆款】**：按5方向分类（反常识认知/做IP方法论/高客单成交/AI+商业/搞钱变现），每条标注：标题、平台、账号、赞数、核心观点、对标判断结论（值得对标/不值得对标/不可放大/待补证据）、优先级
2. **【全网采集爆款】**：关键词全网搜索其他爆款（不限于对标），同样5方向分类标注；**淘汰必须写明原因**（如"人群淘汰：泛C端围观型，非从业者"），便于追溯筛选逻辑
3. **【合并分析】**：两部分合并后给出——方向×优先级分布统计 + 一句话结论（最强方向池在哪 / 差异化切口在哪 / AI类承接在哪）
4. **【平台观察】**：各平台近30天动态各1句（如"视频号B端知识IP爆款少于抖音，头部集中在电商私域链路"），只作参考不直接产出选题
5. **【Top3改写】**：挑最适合用户做的3条（**只从"值得对标+高优先级"中选**），改写成用户风格（测评获客、高客单方向）
6. **【每日推荐1条】**：4要素缺一不可：
   - ① **我的版本**：完整标题 + 钩子 + 内容方向
   - ② **原标题**：原句一字不改 + 原平台 + 原账号 + 原赞数（用户靠这个判断值不值得洗）
   - ③ **为什么推荐**：2-3句（原爆款爆在哪/和我的匹配点：人群/客单价/打法）
   - ④ **形式**：视频（钩子强/需口播/情绪冲击/反常识判断）或图文（清单/避坑/方法论拆解/收藏型）

## 可配合定时任务

每天定时触发（见 `doubao-cron-scheduler`），跑完把【每日推荐】写进工作台 HTML 快照（见 `inspiration-board`）。

## 验收

- [ ] 两部分齐全（对标+全网）
- [ ] 30天/百赞门槛
- [ ] 每日推荐4要素齐全

## 衔接

选中的推荐直接丢给 `viral-rewrite`（洗稿）或 `ai-retell`（AI重讲洗稿）成稿。
