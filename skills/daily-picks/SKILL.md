# 每日爆款推荐

每天输出固定结构：两部分选题 + 1条每日推荐。

## 采集

- **平台**：小红书、抖音、视频号
- **对标账号**：用户的对标池（来自 `benchmark-finder`，或用户指定）
- **关键词**：`keyword-generator` 输出的15个
- **筛选**：最近30天 + 百赞以上

## 输出结构

1. **【对标账号爆款】**：按5方向分类（反常识认知/做IP方法论/高客单成交/AI+商业/搞钱变现），每条标注：标题、平台、账号、赞数、核心观点
2. **【全网采集爆款】**：关键词全网搜索其他爆款（不限于对标），同样5方向分类标注
3. **【Top3改写】**：挑最适合用户做的3条，改写成用户风格（测评获客、高客单方向）
4. **【每日推荐1条】**：4要素缺一不可：
   - ① **我的版本**：完整标题 + 钩子 + 内容方向
   - ② **原标题**：原句一字不改 + 原平台 + 原账号 + 原赞数（用户靠这个判断值不值得洗）
   - ③ **为什么推荐**：2-3句（原爆款爆在哪/和我的匹配点：人群/客单价/打法）
   - ④ **形式**：视频（钩子强/需口播/情绪冲击/反常识判断）或图文（清单/避坑/方法论拆解/收藏型）

## 可配合定时任务

每天定时触发（见 `doubao-cron-scheduler`），跑完把【每日推荐】写进工作台 HTML 快照（见 `inspiration-board`）。

## 验收

- [ ] 两部分齐全（对标+全网）
- [ ] 30天/百赞门槛
- [ ] 每日推荐4要素齐全

## 衔接

选中的推荐直接丢给 `viral-rewrite`（洗稿）或 `ai-retell`（AI重讲洗稿）成稿。
